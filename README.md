\# ✈️ Vai Voando - Agência de Viagens



Site completo para agência de viagens com sistema de login, painel administrativo e integração com WhatsApp.



\## 🚀 Funcionalidades



\- ✅ Sistema de Login (Cliente/Administrador)

\- ✅ Painel Administrativo (CRUD de destinos)

\- ✅ Carrossel interativo de destinos

\- ✅ Compra direta via WhatsApp

\- ✅ Design 100% responsivo

\- ✅ Banco de dados Neon (PostgreSQL)

\- ✅ Hospedagem na Vercel
